# Public research publication policy, Milestone 26

The current repository was verified PUBLIC at the M26 preflight. This current
user-authorized state supersedes the visibility instruction in the historical
`PRIVATE_PUBLICATION.md`; the historical sanitization record is preserved.
No visibility change is part of M26. The sanitized checkout and `github` remote
remain the only publication source. Never import or rewrite unsanitized history.

Public code, appropriately licensed source references and generated synthetic
numerical tables/vector figures are permitted deliverables. Raw medical data,
participant information, individual derivatives, real model weights, credentials,
permission agreements, local paths and private configuration remain excluded.

Existing M20/M21 permission checks and all unsupported/blocked human uses remain
unchanged. No data or models were downloaded for the M26 synthetic experiments.

Every release must retain privacy checks, full reachable-history secret scanning,
distribution payload inspection and required CI gates. Synthetic binary figures
are kept in ignored local receipts; public M26 figures are reviewable SVG text.
No scanner rule or reviewed false-positive exception is expanded for M26.
Only verified changes may be merged; no force push or visibility change.
