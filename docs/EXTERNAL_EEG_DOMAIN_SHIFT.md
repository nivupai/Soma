# External EEG domain shift

Only metadata shift is observed for the human candidate. EEGBCI and BNCI differ
in native sampling, reference-channel scope, acquisition filtering, montage and
cue origin. Nine common ROI names do not recover the average of missing source
channels or establish identical physical electrode positions. Resampling changes
the input transform; binary selection changes a four-class task into a declared
two-class endpoint. Neither is hidden as exact original-model transfer.

No external human amplitude, spectral, covariance, rejection-rate, session,
confidence or error distribution was measured. Those fields remain NOT_RUN.
Original M22 BA60.77% is not assigned to the new dataset. Hardware differences
alone do not demonstrate physiological differences or explain an unobserved
performance deterioration.

For permitted controlled executions, `external_domain_shift` reports equal-subject
RMS microvolts, mean log mu/beta power, class fraction and affine-invariant distance
to a covariance mean fitted on source data only. Subject/session membership,
coverage and prediction metrics accompany the receipt. These are observable
measurement summaries, not causal attributions. Fictional sessions exercise those
calculations with independently generated trials; perfect or near-perfect toy
scores are numerical reference behavior, not estimates of human generalization.
