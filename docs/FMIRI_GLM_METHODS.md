# Task-fMRI GLM methods (Milestone 13)

BOLD is a vascular/hemodynamic signal coupled indirectly to neural activity.
It is neither neuronal current nor EEG oscillatory power. This engine models
already processed data with declared provenance; it does not implement motion,
distortion or slice-timing correction and does not infer preprocessing from BIDS.
The SPM example has an explicit, limited raw educational exception.

FunctionalRun keeps the 4D image separate from anatomical Volume: time samples,
TR seconds, finite image values, coded qform/sform, mm image coordinates/RAS metre
Soma geometry, binary aligned mask, exact run identities, events, confounds,
processing space and source evidence are validated. Loading reuses Soma's strict
NIfTI geometry. Shapes alone never establish alignment. A run is processed at a
time with n_jobs1; full residuals are retained for diagnostics, not all subjects.

Design is generated by Nilearn0.14.1 make_first_level_design_matrix, oversampling50,
SPM or Glover HRF (optional temporal derivative), selected drift model/intercept,
scan times (arange(n)+slice_time_ref)*TR and explicit nuisance columns. The event
boxcar is convolved with the chosen HRF and sampled at acquisitions. Negative or
out-of-coverage events fail conservatively. Duplicate names, nonfinite values,
rank deficiency, condition number>1e10 and residual DOF<=0 fail. Nilearn may warn
and regularize singular designs; Soma rejects the resulting near-singular matrix.
Collinearity/correlation, event counts, timing and actual names are reported.

No volumes are silently dropped. Selected confounds must exist and align to all
samples. Motion derivatives use a declared zero first derivative; measured FD
can generate individual one-hot spikes above a declared threshold. Only the first
undefined FD may become zero by explicit policy; other missing values fail.
Physiological regressors can be explicitly selected if provided. No columns are
fabricated. Drift is modeled jointly with task/nuisance rather than independently
filtering Y while leaving X unchanged. Trend derivatives/spikes that create linear
dependence are rejected. Four initial spikes are a fixed SPM educational setting.

Production estimation uses Nilearn FirstLevelModel with explicit design matrices,
standardize=False and signal_scaling=False. Effects remain native BOLD units per
modeled regressor unit, not percent signal change. OLS assumes spherical temporal
noise; feasible AR(1) estimates/bins voxel autoregressive coefficients (100 bins)
and whitens the model. This is approximate GLS, not known-covariance exact GLS.
Native and whitened residual lag-one diagnostics, variance, design condition and
Nilearn residual DOF are saved. Feasible finite-sample AR(1) can remain miscalibrated.
Smoothing uses explicit FWHM in millimetres, independent of noise whitening.

Contrast accepts named condition weights or a finite vector in actual design
order. Missing conditions, all-zero/wrong-length vectors and nonestimability fail.
Signed effects/variance/t/z maps remain accessible. Two-sided p=2*normal.sf(abs(z))
uses Nilearn's signed t-to-normal conversion and residual DOF; scipy BH adjustment
operates over every analysis-mask voxel for each contrast. q<=.05 is the default
rejection rule. This is not cluster inference or FWE correction. BH guarantees
require suitable dependence assumptions; measured simulation behavior is reported,
not replaced by a universal calibration claim. The supplied raw SPM example is
exploratory even when a statistical threshold is applied.

Within-subject fixed effects delegate to Nilearn compute_fixed_effects with
precision weighting and run DOFs. Subject/task/space, distinct runs, grid/mask and
contrast definitions must agree. Shared explicit effect-scale provenance and
matching HRF basis/smoothing are also required; arbitrary native intensity scales
cannot silently be pooled. Contrast metadata records HRF/noise/smoothing identity.
They do not estimate population random effects.
ROI mean effects are descriptive. A mean of voxel variances is not an ROI contrast
standard error; spatial covariance is not modeled here and ROI inference is marked
unavailable. No activation-selected ROI is used for the primary demonstration.

first_level_from_bids was inspected in the installed version. Soma uses PyBIDS
selection plus explicit FirstLevelModel construction so raw/preprocessing evidence,
space ambiguity, mask and confound requirements cannot be silently bypassed by
high-level discovery defaults. Neither API implies validated external preprocessing.

Primary APIs: [Nilearn first-level model](https://nilearn.github.io/stable/modules/generated/nilearn.glm.first_level.FirstLevelModel.html),
[BIDS integration](https://nilearn.github.io/stable/modules/generated/nilearn.glm.first_level.first_level_from_bids.html).
