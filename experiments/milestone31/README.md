# Frozen M31 synthetic inverse-prior experiment

Protocol: `design.json`, locally committed and sealed before final outcomes.
The seal is local provenance, not external preregistration. See
`docs/MILESTONE31_PROTOCOL.md` and `docs/MILESTONE31_RESULTS.md`.

Reproduction, from repository root with the documented optional FEM/mesher stack:

```
python -m scripts.run_inverse_calibration --output reports/m31-reproduction --local reports/m31-physical
python -m scripts.summarize_inverse_calibration reports/m31-reproduction --output reports/m31-summary
```

The summarizer also writes the packaged Explorer example; inspect/review its hash
before using it for a release. It never changes M30 scientific results. For a
read-only comparison, use CSV/JSON results in the chosen output directory.

- `M30-replication.csv`: recomputed historical kernels/noise/source rows.
- `reconstructions-head*-block*.csv`: all 99,360 actual reconstruction records,
  partitioned by head and source-ID block solely to keep reviewable text files.
- `sources.json`, `measurements-*.csv`, `truth-new-*.csv`: exact synthetic generators,
  matched measurement vectors and fresh off-grid finest FEM truth.
- `grid-*.csv`: exact ordered positions and approximate Voronoi cell volumes.
- `operators.csv`, `point-spread.csv`: prior/regularization/spectrum/resolution/PSF
  diagnostics; dSPM spatial response units differ from physical moment kernels.
- `regularization-curves.csv`: calibration-repeat losses, not test-selected optima.
- `heldout-summary.csv`, `new-heldout-only.csv`, `paired-contrasts.csv`: distinct
  primary conditional intervals, new-seed sensitivity and paired changes.
- `prior-covariance.csv`, `BEM-FEM-paired.csv`: sensor-space and two-head sensitivities.
- `figures/*.svg`: twelve actual-data figures, generated by the public summarizer.
- `receipt.json`, `execution.json`, `replay-audit.json`: resource/provenance receipts
  and independently regenerated truth/row comparison. Runtime/RSS are not expected
  to be byte-reproducible.
- `baseline-release-blocker.json`: observed M30 post-merge native signature change;
  the gate remains blocking. No original failure is relabeled or suppressed.
- `manifest.json`: SHA256 of every public file here except the manifest itself.

All content is synthetic. No participant records, raw medical data or licensed
model weights are included. Fixed-mesh numerical portability does not establish
native meshing portability or human anatomical validity.
